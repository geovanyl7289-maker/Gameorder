# Gameorder 1.8.3

作者：**XIAOYING223**

本次更新修正离线登录状态显示，并减少 Gameorder 的后台活动。确认离线登录后，账号头像、快捷头像栏与任务栏入口同步显示「离线登录」；隐藏主界面与快捷面板后自动采用后台节能策略。

## 本次更新

- 修正离线登录显示；Steam 未运行时仍显示「离线」。
- 主界面与快捷面板都隐藏时降低自身进程优先级，并在系统支持时启用 EcoQoS；打开界面或正在切换时恢复交互策略。
- 常规前台每 5 秒读取状态，常规后台每 15 秒读取，游戏期间每 20 秒读取。
- 周期状态读取移到不重叠的后台任务，丢弃过期结果，减少未变化状态造成的界面与托盘更新。
- 减少稳定任务栏布局的重复检查，结构变化后重新确认布局。
- 保留游戏期间暂时收起组件、结束后按原偏好恢复的行为。

## 下载与使用

下载 Windows x64 程序包，解压后运行 `Gameorder.exe`。自包含发布包已包含 .NET 运行时。

密码和 Steam Guard 在 Steam 官方窗口中完成。离线启动要求本机已有该账号的有效登录缓存。切换会重启 Steam，请先保存游戏进度。

状态随 Steam 本机信息更新，可能稍有延迟。后台节能减少的是 Gameorder 自身的活动，不承诺固定 CPU 降幅或提升游戏帧率。

详细操作见程序包内的使用说明；完整更新记录见仓库中的 `CHANGELOG.md`。
