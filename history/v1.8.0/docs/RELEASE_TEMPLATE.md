## 下载与使用

下载 Windows x64 程序包，解压后运行 `Gameorder.exe`。自包含发布包已包含 .NET 运行时。

密码和 Steam Guard 在 Steam 官方窗口中完成。离线启动要求本机已有该账号的有效登录缓存。切换会重启 Steam，请先保存游戏进度。

详细操作见程序包内的使用说明；完整更新记录见仓库中的 `CHANGELOG.md`。
